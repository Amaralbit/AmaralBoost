AVANÇADO

Limite de RAM para navegadores

⚠

Recurso avançado, não é 100% reversível na hora. Ao bater no teto, o Windows pode fechar uma aba ou travar o navegador — é assim que um limite de memória por processo funciona. Ao desativar, processos novos deixam de entrar no limite, mas quem já estava dentro continua limitado até fechar (o Windows não permite soltar um processo de um limite já aplicado). O limite não sobrevive a reiniciar o Windows — depois de reiniciar, reabra o Amaral Boost para retomar.
